# SpeakFlow

Личное приложение для практики разговорного английского. Это обычный сайт
(не артефакт Claude), поэтому доступ к микрофону в Safari на iPhone будет
работать как в любом нормальном сайте — через стандартный запрос разрешения
браузера, без ограничений iframe-песочницы.

## Что нужно один раз сделать

1. **API-ключ Anthropic.** Зайди на https://console.anthropic.com → API Keys →
   создай ключ (нужен привязанный платёжный метод — API тарифицируется
   отдельно от подписки Claude.ai). Ключ выглядит как `sk-ant-...`.
   Никогда не вставляй его в код и не публикуй — он живёт только в
   переменных окружения Vercel (шаг 4).

1a. **API-ключ ElevenLabs** (озвучка ответов ИИ). Зайди на
    https://elevenlabs.io → зарегистрируйся → Profile → API Keys → создай
    ключ (`sk_...` или похожий формат). Есть бесплатный лимит символов в
    месяц, дальше — платные планы. Как и ключ Anthropic, никогда не
    публикуй его — он тоже живёт только в переменных окружения Vercel.

2. **Аккаунт на Vercel** — https://vercel.com, можно войти через GitHub.

3. **Выложить этот код в GitHub-репозиторий** (самый простой способ):
   - Создай новый пустой репозиторий на github.com.
   - В папке проекта:
     ```
     git init
     git add .
     git commit -m "SpeakFlow MVP"
     git branch -M main
     git remote add origin https://github.com/<твой-юзернейм>/speakflow.git
     git push -u origin main
     ```

4. **Задеплоить на Vercel:**
   - На vercel.com → "Add New… → Project" → выбери репозиторий `speakflow`.
   - Vercel сам определит, что это Vite-проект — ничего менять не нужно.
   - Перед деплоем открой "Environment Variables" и добавь:
     `ANTHROPIC_API_KEY` = твой ключ из шага 1, и
     `ELEVENLABS_API_KEY` = твой ключ из шага 1a.
   - Нажми Deploy. Через минуту получишь ссылку вида
     `https://speakflow-xxxx.vercel.app`.

5. **Открой эту ссылку в Safari на iPhone**, при первом нажатии на микрофон
   браузер спросит разрешение — подтверди. Дальше всё должно работать как в
   обычном приложении. Можно добавить на домашний экран
   (Поделиться → "На экран «Домой»"), тогда будет открываться как отдельное
   приложение, в полный экран.

## Локальная разработка (по желанию)

```
npm install
cp .env.example .env.local   # впиши туда свой ключ
npm run dev
```

Откроется на `http://localhost:5173`. `npm run dev` не поднимает
serverless-функцию `/api/chat` сама по себе — для локальной проверки именно
API можно поставить `vercel dev` (`npm i -g vercel`, затем `vercel dev`)
вместо `npm run dev`.

## Структура

- `src/App.jsx` — всё приложение (все экраны: Home, Speaking Session,
  Session Debrief, Live Club Debrief, Progress, Weak Spots).
- `api/chat.js` — серверная функция, которая держит API-ключ и общается с
  Anthropic от имени клиента. Ключ никогда не попадает в браузер.
- `api/speak.js` — серверная функция озвучки: держит ключ ElevenLabs и
  превращает ответы ИИ в аудио (женский американский голос). Ключ тоже
  никогда не попадает в браузер.
- Данные (сессии, фразы, слабые места) хранятся в `localStorage` браузера —
  то есть остаются только на этом устройстве. Если захочешь синхронизацию
  между устройствами, это отдельная следующая фича, не MVP.
